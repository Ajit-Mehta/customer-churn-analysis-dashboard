# Customer Churn Analysis Dashboard

## Project Overview
This project is an interactive Customer Churn Analysis Dashboard built using Power BI. The dashboard helps analyze customer churn behavior, retention patterns, contract trends, internet service usage, and payment methods.

The main objective of this project is to identify factors contributing to customer churn and generate actionable business insights using data visualization and DAX measures.

## Tools Used
- Power BI
- DAX
- Power Query
- Microsoft Excel

## Key KPIs
- Total Customers
- Total Churn Customers
- Churn Rate
- Average Monthly Charges

## Dashboard Features
- Churn Analysis by Contract Type
- Churn Analysis by Internet Service
- Payment Method Analysis
- Monthly Charges Comparison
- Tenure-Based Customer Analysis
- Interactive Slicers and Filters

## Key Insights
- Month-to-month customers have the highest churn rate
- Fiber optic users show higher churn behavior
- Electronic check users are more likely to churn
- Customers with lower tenure churn more frequently
